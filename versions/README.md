# CHAK 메인 소개 버전

## v1 — 토글 / 모바일 1개

- 미리보기: `chak-toggle-v1.html#chak` (저장 당시 메인 전체와 CHAK 섹션)
- 저장한 스타일: `chak-toggle-v1.css`
- 복원용 CHAK 섹션 원문: `chak-toggle-v1-section.html`
- 당시의 소개 문구와 사용자가 수정한 하단 정보도 그대로 보존했다.
- 미리보기는 상위 폴더의 이미지·공통 CSS·JavaScript를 사용하며, 메인 레이아웃 CSS는 저장본을 사용한다.

## v2 — 토글 없음 / 모바일 2개

현재 `../index.html#chak`에 적용된 버전이다. 기존 홈과 개선 와이어프레임을 동시에 보여준다. 데스크톱에서는 나란히, 480px 이하에서는 읽기 쉽도록 세로로 배치한다. 소개 문구와 하단 정보는 v1의 내용을 유지한다.

v1로 복원하려면 메인의 CHAK 섹션을 저장된 섹션 원문으로 교체한다. v2 스타일은 `project--chak-comparison`에 한정되어 있어, 해당 클래스가 없는 v1에서는 적용되지 않는다.
